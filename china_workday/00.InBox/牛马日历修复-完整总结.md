```python
async def _load_cache(cache_path):
    def read_file():
        with open(cache_path, "r", encoding="utf-8") as f:
            return f.read()

    loop = asyncio.get_event_loop()
    content = await loop.run_in_executor(None, read_file)
    return json.loads(content)
```

#### b) `_save_cache()` 函数（第 350-363 行）
```python
async def _save_cache(cache_path, data):
    def ensure_dir_and_write():
        cache_path.parent.mkdir(parents=True, exist_ok=True)
        json_content = json.dumps(data, ensure_ascii=False, indent=2)
        cache_path.write_text(json_content, encoding="utf-8")

    loop = asyncio.get_event_loop()
    await loop.run_in_executor(None, ensure_dir_and_write)
```

## 🔧 技术细节

### 异步/同步混合模式

```
初始化阶段（异步）
    ↓
async_added_to_hass()
    ↓
_precalculate_important_date()  [调用API，计算重要日期]
    ↓
缓存到 _cached_next_date
    ↓
每日更新（同步，快速）
    ↓
update_data()
    ↓
_get_next_important_date()  [读取缓存，O(1)]
    ↓
每日监听器（异步）
    ↓
point_in_time_listener()
    ↓
_daily_recalculate()  [后台任务，重新计算]
```

### 关键改进

1. **预计算机制**
   - 初始化时立即计算，避免首次延迟
   - 结果缓存，后续查询快速响应

2. **异步非阻塞**
   - 文件I/O使用 `run_in_executor`
   - API调用在异步上下文执行
   - 不阻塞Home Assistant事件循环

3. **每日自动更新**
   - 重写 `point_in_time_listener`
   - 每天午夜自动重新计算
   - 确保数据始终最新
