# 牛马日历 - 在线API版本

## ✅ 最终方案

使用**在线API**获取节假日和农历数据，**无需额外依赖**。

## 📦 依赖

**仅需一个依赖**：
```json
{
  "requirements": ["holidays==0.84"]
}
```

## 🎯 功能

### 1. 节假日数据
- **API来源**: `https://timor.tech/api/holiday/year/{year}`
- **离线备用**: 内置静态数据（2024-2026年）
- **缓存**: 30天自动更新

### 2. 农历转换
- **API来源**: `http://timor.tech/api/lunar/calendar`
- **支持格式**: `L02-27=生日`（农历二月二十七）
- **实时转换**: 自动转换农历到公历

### 3. 重要日期配置

支持**公历+农历**混合使用：

```
# 公历日期
01-01=元旦,05-20=纪念日,12-25=圣诞节

# 农历日期（L开头）
L01-01=春节,L02-27=生日,L08-15=中秋节

# 混合使用
01-01=元旦,L02-27=生日,05-20=纪念日
```

## 🚀 部署步骤

### 1. 复制文件到 Home Assistant

```bash
# 通过 Samba 或 Configurator
\\homeassistant\config\custom_components\china_workday\
```

### 2. 重启 Home Assistant

```
设置 -> 系统操控 -> 重启
```

### 3. 配置集成

```
设置 -> 设备与服务 -> 添加集成 -> 中国工作日

配置示例：
- 工作日: 周一到周六

- 大周小周: 开启
- 大周开始日期: 2026-01-12
```

| 下个法定节假日时长 | 3 天 |

## ⚠️ 注意事项

### API依赖

- 需要**网络连接**才能获取最新数据
- API失效时自动使用**静态备用数据**
- 30天自动**刷新缓存**

### 农历API

- 使用**timor.tech**的免费API
- 可能受**Cloudflare保护**
- 如果API频繁失败，建议**使用公历日期**

### 配置建议

**最佳实践**：
1. 优先使用**公历日期**（如 `05-20=纪念日`）
2. 重要农历日期可以使用API转换（如 `L02-27=生日`）
3. 定期检查传感器数据是否正常

## 🔧 故障排查

### 问题1: 农历日期不工作

**症状**: 农历重要日期显示"未知"

**原因**: API被保护或网络问题

**解决**: 改用公历日期
```
# 修改前
L02-27=生日

# 修改后（查找今年对应公历日期）
03-27=生日(农历)
```

### 问题2: 节假日数据过期

**症状**: 节假日显示不正确

**解决**:
1. 删除缓存：删除 `.storage/china_workday/china_holidays_cache.json`
2. 重启 Home Assistant
3. 强制刷新数据

### 问题3: API请求失败

**症状**: 日志显示API错误

**影响**: 自动使用静态备份数据（2024-2026年）

**解决**: 无需处理，静态数据已足够使用
